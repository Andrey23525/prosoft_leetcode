# Задачи
Каждая задача лежит в своей папке в "src" и собирается в отдельную статическую библиотеку, тесты в "tests". Сигнатуры задач описаны в заголовке "include/problems.h". Общие зависимости вынесены в "include/shared/stdafx.h" и подключаются как precompiled header через cmake.
Собрать и прогнать тесты:

cmake -S . -B build <br/>
cmake --build build <br/>
ctest --test-dir build <br/>

## Two Sum

Дан массив и число target, надо вернуть индексы двух элементов, которые в сумме дают target.

Внешний цикл фиксирует первый индекс, внутренний идёт правее (индекс на 1 больше внешнего) и проверяет сумму. 
Условие задачи гарантирует, что единственная подходящая пара существует.

## Binary Search

Отсортированный массив, нужен индекс target или -1, если его нет.

Используется "std::lower_bound" в качестве бинарного поиска. Он возвращает первый элемент, который не меньше target. 

Вывод этой функции нужно проверить: 
1. Не равно ли концу входного массива
2. Совпало ли найденное значение с искомым 

Если условия выполнились, то возвращаем расстояние от начала до найденного элемента.
Приведение к int, как требуется по условию задачи

## Add Two Numbers

Два числа заданы односвязными списками. Младший разряд числа в начале списка.

На каждом шаге берётся цифра из первого списка (или ноль, если он уже кончился), цифра из второго и к ним прибавляется перенос. Перенос также является цифрой.
В новый узел уходит остаток от деления на 10, а перенос — это целая часть. 
Цикл крутится, пока жив хоть один список или пока остался ненулевой перенос.

В тестах за временем жизни следит "OwnedList", который держит узлы в векторе как unique_ptr.

## Max Points on a Line

Надо найти, сколько точек максимум лежит на одной прямой.

Прямая задаётся парой точек, поэтому каждая точка по очереди становится опорной, и от неё считаются направления до всех точек правее (индекс больше, как в первой задаче) по списку. Лежащие точки на одной прямой с опорной дают одинаковое направление. Достаточно сложить направления в "map" и взять самое частое, прибавив саму опорную точку.
Вектор (dx, dy) остаётся целым, но делится на НОД и при необходимости разворачивается, чтобы знак был фиксированным (dx > 0, а если dx нулевой, то dy > 0).
Любая прямая с k точками найдётся в тот момент, когда опорной станет первая из них по порядку в массиве. 
Минимальный возможный ответ задачи - 2, потому что через любые две точки прямая проходит всегда.
Вырожденные случаи с одной-двумя точками отсекаются сразу на входе.

## Basic Calculator

Нужно посчитать строку с числами, плюсами, минусами, пробелами и скобками. 

Сложность заключается в вложенных скобках. Минус перед скобкой переворачивает знаки всех внутренних операций.
На вершине стека лежит знак, с которым берётся текущий уровень вложенности. 
Если встретили "(", то текущий знак добавляется в стек, он теперь действует на всё содержимое скобки.
Парный знак ")" его оттуда снимает. 
Сами операции "+" и "-" сразу задают знак следующего числа: плюс сохраняет знак уровня как есть, а минус изменяет его. 
Как только очередное число прочитано, то оно со своим знаком прибавляется к результату.
Получается один проход по строке. Цифры считаются на месте внутренним циклом, а после него индекс откатывается на единицу, чтобы внешний "++i" не перепрыгнул символ, стоящий сразу за числом. 
Накопитель — "long long": итог по условию влезает в 32 бита, но промежуточные суммы необходимо держать с запасом, а возвращать из функций "int". Последние тесты ориентированы именно на этот баг с переполнением.
